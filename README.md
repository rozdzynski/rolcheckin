# RŌL Check-In

Instructor check-in and HR app for RŌL Academy (Orland Park, IL).

- Live site: https://rolcheckin.netlify.app
- The whole app is `index.html` (plain HTML/CSS/JavaScript), backed by Supabase.
- `manifest.json` and the icons let staff add it to their phone's home screen.

The version number is in the login footer (`v2026.MM.N`).
